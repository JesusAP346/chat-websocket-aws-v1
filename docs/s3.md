# S3 (Frontend)

## Descripción

Se utiliza Amazon S3 para almacenar el frontend de la aplicación, el cual consiste en una página web estática (`index.html`) que permite a los usuarios conectarse al sistema de chat.

El bucket actúa como origen de CloudFront, desde donde se sirven los archivos estáticos.

---

## Configuración

Se creó un bucket S3 con las siguientes características:

* Contiene el archivo `index.html`
* No se utiliza el modo *Static Website Hosting*
* El acceso público está bloqueado
* Se utiliza junto con CloudFront como origen

---

## Integración con CloudFront

El bucket S3 no es accesible directamente por los usuarios.

El flujo es:

```text id="xj4d9q"
User → CloudFront → S3
```

CloudFront se encarga de solicitar los archivos al bucket y entregarlos al usuario.

---

## Seguridad

Para proteger el contenido:

* Se bloqueó el acceso público al bucket
* Se configuró una policy que permite acceso solo desde CloudFront
* Se utiliza Origin Access Control (OAC)

Esto garantiza que:

* Los usuarios no pueden acceder directamente al bucket
* Todo el tráfico pasa por CloudFront

---

## Contenido del frontend

El archivo principal es:

```text id="c0fj6p"
index.html
```

Este archivo contiene:

* Interfaz básica para enviar mensajes
* Código JavaScript que establece la conexión WebSocket
* Uso del endpoint de API Gateway (WSS)

>[!TIP]
>
>Se tiene 2 archivos index.html en la carpeta *frontend*. Cada uno con diferentes diseños, se puede usar cualquiera de los dos.


---

## Relación con API Gateway

El frontend alojado en S3 se encarga de iniciar la conexión WebSocket.

```text id="i9m2yo"
Browser → API Gateway (WSS)
```

Esto significa que:

* S3 solo almacena y sirve el frontend
* No participa en la lógica del backend
* La comunicación en tiempo real se realiza directamente con API Gateway

---

## Consideraciones

* Al no usar Static Website Hosting, el acceso es únicamente a través de CloudFront
* Cambios en el frontend requieren actualización del archivo en el bucket
* Puede ser necesario invalidar caché en CloudFront para ver cambios inmediatos
